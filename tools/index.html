Which tool do I need?

Three questions that cover most visits.

I just need a word count

Open the character counter. It shows a live word count plus characters, sentences and reading time in one panel.

I need to know how long my document is

Use the words to pages calculator. Set the font, size and line spacing, then read the page count for your word count.

I need to count characters for a post

The Twitter counter weights links and CJK characters the way X does. Every other platform limit sits in the same table.
