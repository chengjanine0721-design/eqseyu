How to convert text to lowercase

  1. Paste or type your text into the Input box.
  2. Click lowercase, the result appears in the Output box immediately.
  3. Copy the result, or download it as a.txt file.

Nothing is uploaded. The conversion uses your browser's native Unicode case mapping, so accented characters (Ä → ä, İ → i̇) and non Latin scripts convert correctly.

Which case should a URL slug use?

kebab case is the safest choice for URLs: lowercase letters, words joined by hyphens, no spaces. That's exactly the pattern this site uses (/tool/lower case generator/). Avoid camelCase in URLs, some servers treat capital letters inconsistently, and underscores in URLs can be misread as spaces when underlined in a link.

Frequently asked questions

Does lowercase conversion change the character count?
No. Only letter case changes. Length stays identical.
What's the difference between lowercase and Sentence case?
lowercase makes every letter small. Sentence case keeps the first letter of each sentence (and the pronoun "I") capitalised while lowercasing everything else.
Why does my camelCase output lose punctuation?
camelCase, snake_case and kebab case are identifier styles, so punctuation and extra spaces are collapsed into word boundaries, that's what makes the result usable as a variable, column name or URL slug.
Does it work with Turkish or German characters?
Yes, it uses the browser's Unicode case mapping. Note that Turkish dotted/dotless i follows standard Unicode rules, not Turkish locale rules.
Is there a length limit?
No practical limit, tens of thousands of characters convert instantly.

Case questions

Two things readers ask most.

What is camel case used for?

Variable and function names in JavaScript, Java and Swift, where the first word stays lower and each later word is capitalized.

Do accents and other scripts convert correctly?

Yes. Accented letters keep their case mapping and scripts without case pass through unchanged.
